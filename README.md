### Hi ✋ I'm Jonathan

I lean towards systems programming and like optimising things.

I'm doing a PhD in Physics at the University of York, testing whether spiking neural networks really are more robust than conventional ones. Before that I spent two years at AWS on [Firecracker](https://github.com/firecracker-microvm/firecracker), the virtual machine monitor behind AWS Lambda, and helped maintain [rust-vmm](https://github.com/rust-vmm).

Outside of that I'm building [formal](https://github.com/JonathanWoollett-Light/formal), a compiler for bare-metal RISC-V that only accepts a program once it's proved no assertion can fail and no memory access can go out of bounds, and I make Hearts of Iron IV mods.
